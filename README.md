# rAInmaker Lite

This repo includes the actual, working `SKILL.md`, the same file that ships in the free download at [skillfaire.com/rainmaker.html](https://skillfaire.com/rainmaker.html). See "Install" below for the two different setup paths depending on how you run Claude.

## What it is

rAInmaker Lite is the free tier of rAInmaker, a Claude Skill that coaches you on real sales situations in the same blunt, no-flattery voice as the paid version, capped to one job plus a taste of a second.

It reviews and sharpens cold emails, LinkedIn messages, cold-call openers, and voicemail scripts. It also runs one full-quality Spar roleplay per conversation, a real AI buyer, real resistance, so you can feel what being coached through a live call is actually like, not just read about it. That one session is full quality, it just stops before the scorecard.

It doesn't do deal tracking, discovery, objections, proposals, closing, or pipeline coaching, doesn't run a second roleplay in the same conversation, has no memory between sessions, and only works in English. That's not a limitation that snuck in, it's the shape of a free taste on purpose.

## Install

**Claude Code or the Agent SDK.** Clone or download this repo and drop the `rainmaker-lite` folder into your skills directory. That's it.

**claude.ai in the browser.** The web uploader needs a zip, not a raw folder, so get the ready-built one from [skillfaire.com/rainmaker.html](https://skillfaire.com/rainmaker.html) instead of zipping this folder yourself. Turn on code execution in Settings, Capabilities, then go to Customize, Skills, and upload it there. The site also bundles two free extras, `natural-voice` and `anti-slop`, which sharpen anything Lite rewrites, worth grabbing at the same time, they're not part of any paid upsell.

## What it feels like to use

Bring it a real draft, not a hypothetical, and ask for a review or a rewrite. Expect a question back first, usually about what actually changed that makes now the moment to send it, then the single biggest problem named plainly, and one concrete fix, not a full rewrite handed to you. It hands the draft back and asks for your attempt before touching the wording itself.

Ask for a roleplay and it plays a specific, resistant buyer for real, then breaks character cleanly before giving you an honest read on what worked and what would have lost the deal, in plain sales-manager language. You get one of those per conversation.
